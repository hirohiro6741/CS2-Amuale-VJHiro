# Electricity Bill Calculator

## Description
This program calculates electricity bills based on previous and current meter readings.

## Version 1 - Original code without input validation
- Input: Accepts the user's name and two electricity bills, that being the previous and current meter readings.
- Process: Calculates and displays the total electricity bill.
- Output: Total electricity bill.
- Does not include input validation.

## Version 2 - Modified code with input validation
- Adds input validation accepting only viable input
- Includes input validation
